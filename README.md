# .github

This repository powers the public **Klubkern** organization profile.

- [`profile/README.md`](profile/README.md) is what visitors see on
  [github.com/klubkern](https://github.com/klubkern).
- [`profile/assets/`](profile/assets) holds the Klubkern logo (SVG + PNG) for
  reuse — including the square mark used as the organization avatar.
