# Security policy

Klubkern stores personal data of club members. We take reports about security
problems seriously and are grateful for them.

## Reporting a vulnerability

Please **do not** open a public issue, discussion or pull request.

Report it privately instead through
[**Report a vulnerability**](https://github.com/klubkern/.github/security/advisories/new)
and describe

- what is affected and how it can be reproduced,
- what an attacker could gain,
- whether you have shared it with anyone else.

Only the maintainers can see the report.

## What to expect

- We confirm your report within **3 working days**.
- We tell you our assessment and a planned fix date within **10 working days**.
- We let you know when the fix is released and, if you want, credit you in the
  release notes.

Please give us a reasonable time to fix the problem before you publish
anything about it.

## Scope

In scope is everything in the repositories of this organisation and the hosted
Klubkern service. Out of scope are findings that need physical access to a
device, social engineering, and denial of service through sheer load.
